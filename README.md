## Auto Tweeting Script

This repository includes `twitter_auto_poster.py` which can tweet random tips about Python and Pine Script.

### Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Set the following environment variables with your Twitter API credentials:
   - `TWITTER_API_KEY`
   - `TWITTER_API_SECRET`
   - `TWITTER_ACCESS_TOKEN`
   - `TWITTER_ACCESS_TOKEN_SECRET`
3. Run the script:
   ```bash
   python twitter_auto_poster.py
   ```

Each run will post a tweet with a random tip.
